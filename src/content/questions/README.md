# questions コレクション

1問 = 1ファイル（ファイル名はその日の日付 `YYYY-MM-DD.json`）。スキーマは `src/content.config.ts` で定義。

日付はすべて実在の日付。歴代首相動静を構造化した公開データ（GitHub: isamu/sori、元データは
官邸ログ/kanteilog.com が時事通信・日本経済新聞・朝日新聞の動静を数値化したもの）の
「公務時間(work_min)」「居所滞在時間(residence_min)」「場所」「分類ごとの時間」といった
数値・事実のみを根拠にしている。個々の記事や分類ラベルの原文は引用せず、`text` は
すべてオリジナルで書き下ろした。

- `stay: true` … work_min=0 かつ居所が「公邸」だった日。`text` は定型句で統一（`終日、公邸で過ごす。`）
- `stay: false` … それ以外（work_min>0、または居所が公邸以外だった日）
