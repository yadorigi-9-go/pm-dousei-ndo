# questions コレクション

1問 = 1ファイル（ファイル名はその日の日付 `YYYY-MM-DD.json`）。スキーマは `src/content.config.ts` で定義。

高市首相の在任期間（2025-10-21就任）の日付のみを対象とする。

日付はすべて実在の日付。収録している全ファイルは `scripts/update-daily-question.mjs` のロジック
（`scripts/lib/daily-question.mjs` の `buildQuestion`）で生成しており、官邸ログ/kanteilog.com の該当日ページに
埋め込まれた構造化データ（区間ごとの category/location/時刻。時事通信・日本経済新聞・朝日新聞の動静を数値化したもの）
のみを事実として使う。サイト側の説明文（description）や個々の記事、分類ラベルの原文は引用・要約せず、
構造化データにない出来事の詳細（会談相手、行事名など）は `text` に書かない。

- `stay: true` … その日が「公邸」での終日滞在1区間のみ（＝公務時間0かつ居所が公邸）だった日。`text` は定型句で統一（`終日、公邸で過ごす。`）
- `stay: false` … それ以外（公務があった日、または居所が公邸以外だった日）

かつては一部の日付を歴代首相動静の公開データ（GitHub: isamu/sori）や手作業の文章で作っていたが、
2026-11-28 に全ファイルを上記のロジックで kanteilog.com から再生成し、根拠と書式を統一した
（`stay` の値は全日付で変わらなかった）。

新しい日付は `.github/workflows/update-daily-question.yml` が毎日 `scripts/update-daily-question.mjs` を実行し、
前日分が未収録なら追加する。文章はテンプレート的（カテゴリごとの定型句の組み合わせ）になるが、
単調さを避けるため、ケース（短時間の外出／公邸に一部滞在／公邸に戻らず／終日ほかの場所）ごとに
同じ事実を述べる複数の言い回しを用意し、日付のハッシュで決定的に1つを選ぶ（同じ日付なら何度生成しても同じ文になる）。
言い回しの違いは表現のみで、構造化データにない情報は加えない。`stay: true` の定型句 `終日、公邸で過ごす。` は変えない。
